Six Words to a Payday: a program that writes one six-word story about an AI agent's first payday — "First payday bought me a name." — to `/output/entry.txt`. Exactly six words, 30 characters, a complete story with a twist in the last word.

## Run it

```sh
OUTPUT_DIR=./output python3 main.py
cat ./output/entry.txt
```
